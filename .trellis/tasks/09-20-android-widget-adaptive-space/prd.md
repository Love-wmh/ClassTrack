# 小工具随尺寸放大与平板适配

## Goal

桌面小工具目前在更大的格子上「用不满」：实体卡片里所有排版度量（字号、行距、内边距、列宽、圆角）都是写死的绝对值，格子被拉大后内容不跟着变，用户看到的是「字小 + 大片空白」；平板上 launcher 单格尺寸明显更大，所以这个问题在平板上最刺眼。

本任务让排版度量按**真实格子尺寸连续自适应**，并新增两个可选的展示增强（信息加密 / 双栏）供用户按需打开，同时补齐平板上的验收证据。

## Requirements

### R1 度量随尺寸自适应（默认行为，不需要用户配置）

- 标题 / 正文 / 说明三级字号、行间距、卡片内边距、卡片圆角、时间列与「正在上」标记列的宽度，全部按真实格子尺寸缩放。
- 缩放因子**下限固定为 1.0**：现有绝对值就是小格子的答案，2×2 与手机 4×3 的观感必须与改动前一致。上限为可标定常量（见 accept criteria A1 与 design D1），避免超大格子上文字失控。
- 缩放必须是**连续函数**，由宽与高共同决定；**禁止**引入任何「按尺寸档位渲染」或「`if (height < N.dp) 不显示某个区块`」的分支（D16 的强制约束）。
- 保持 `sizeMode = SizeMode.Exact`；`LocalSize` 仍是宿主格子的真实尺寸；配置页预览与桌面卡片仍然必须一致（WYSIWYG）。

### R2 新增第三组实例级选项「大格子表现」（三选一，默认「跟随尺寸」）

- **跟随尺寸（默认）**：只做 R1 的度量放大，内容与今天完全一致。
- **信息加密**：在 R1 之上，hero 课名放宽到 2 行；课程行补「节次」（快照里已有但从未渲染的 `sections`，如 `3-4`）；汇总行补当天计数（如「已上完 2 节」）。
- **双栏**：在 R1 之上，格子足够宽时把正文切成两栏（左 hero、右当天课表）；不够宽时自动保持单栏，且配置页必须如实说明这条限制。

### R3 配置页

- 新增的第三组选项与现有两组（布局样式、已上完策略）一样**按 widget 实例**保存。
- 旧实例（从未写过该键）打开配置页必须回显默认值「跟随尺寸」，不报错、不空白。
- 三张样式预览缩略图必须反映当前选中的「大格子表现」，且与桌面卡片一致（沿用真实渲染预览路径）。
- 对「双栏在窄格子上不生效」，必须像现有「紧凑样式 vs 已上完策略」那样在页面上如实标注，不能让用户把「选了没反应」当 bug。

### R4 平板

- 平板（sw600dp 以上）上，同一样式、同样 dp 尺寸的观感与手机一致：不得出现「文字明显偏小 + 大片空白」。
- 平板横屏与超大格子上不得出现溢出、裁切或把课名截成不可读的碎片。

### R5 不回归

- 手机最小格子（provider 下限 2×2 格）与常见 4×3 格的观感保持不变（R1 的下限即为此服务）。
- 未选择新选项时，三种布局样式 × 三种「已上完」策略的**内容与顺序逐项不变**。

### R6 不改数据契约

- 不修改 Web → 原生冻结快照契约（保持 `schemaVersion = 1`），不新增跨层字段。
- 「信息加密」只使用快照里**已有**的字段（课名、节次、教室、当天计数），因此本任务不触碰 Web 侧。

### 约束

- C1 日志仍然只能包含阶段名、尺寸/计数类数值与白名单枚举值，**绝不包含课程名、教室、时间或载荷文本**。
- C2 不新增实验性 API 的 `@OptIn` 数量（保持 `ExperimentalGlanceApi` 与 `ExperimentalGlanceRemoteViewsApi` 各一处）。
- C3 「紧凑」样式不显示列表的定位不变；新选项不得让它长出列表。

### 非目标

- 不改 `targetCellWidth/Height = 4x3` 与 `minWidth/minHeight = 110dp`（默认放置尺寸与缩放下限不在本次范围）。
- 不做平板专属的分支布局：双栏只在用户显式选择时启用，且判据是几何比值而非设备类型。
- 不在小工具里显示「第 N 周」：快照没有周次字段，加它要动冻结契约并升级 `schemaVersion`，另开任务。
- 不触碰网页 / PWA / iOS 路径，不改 Web 侧任何文件。

## Acceptance Criteria

- [x] **A1 度量纯函数有 JUnit 覆盖**：下限锁定（2×2 与 4×3 的输入产出与今天的常量完全相同）、对宽高单调不减、上限封顶、两个维度取小（单维度不达标时不放大）、双栏判据的边界值两侧各有断言。
- [x] **A2 未选新选项时内容不变**：三种布局样式 × 三种「已上完」策略的行序列（行种类 + 顺序）与改动前逐项一致，由 JUnit 断言。
- [x] **A3 「信息加密」的新内容有 JUnit 断言**：hero 课名行数、课程行的节次、汇总行的计数文案。
- [x] **A4 门禁全绿**：`testDebugUnitTest` 全绿；`pnpm cap:build:android` 与 `pnpm android:check-assets` 通过；Web 侧未改动。
- [x] **A5 平板实测有据**：平板 AVD（2560×1600 / 280dpi / landscape）上，4×3 与 6×4 两档 × 三种布局样式 × 三种「大格子表现」的截图；`phase=widget_sized` 与 `phase=preview_sized` 的尺寸对得上；无 FATAL / ActionException / InflateException。
- [x] **A6 手机对照组无回归**：手机 AVD（Medium_Phone）上复验 2×2 与 4×3，截图与改动前对照，无溢出/裁切。
- [x] **A7 双栏的判据两侧都有证据**：手机 4×3 不启用，平板 4×3 及以上启用。
- [x] **A8 配置页第三组选项闭环**：选「双栏」→ 确定 → 重开配置页回显「双栏」；从未写过该键的实例回显默认值。
- [x] **A9 诊断日志**：新增一条只含枚举与数值的 `phase=layout_metrics`，白名单同步；日志中不出现任何课程内容。

> 逐条证据（命令、实测输出、截图路径、未验证项）见 [verification.md](./verification.md)。

## Notes

- 「信息加密」的原始设想里包含「第 N 周」，但快照 `schemaVersion = 1` 没有周次字段（`WidgetOccurrence` 只有课名/教室/节次/时间/日期标签），加它属于跨层契约升级，已列为非目标。若后续需要，应单开任务并把契约升级与兼容旧快照一起做。
- 缩放上限是需要标定的常量，不是拍脑袋值：先量平板真实格子尺寸，再定值，并用平板截图前后对比作为变更依据（见 design D1）。
