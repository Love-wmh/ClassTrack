# 课表课程格子改版：彩色实底白字风格

## Goal

把前台课表（`app/features/schedule/`）里课程格子的视觉从「浅色底 + 深色字 + 出勤色描边」改为参考图（wakeup 式课表）风格：**彩色实底渐变 + 白色文字 + 圆角卡片**；同时把「出勤状态表达」和「非本周课程灰色显示」做成个人中心里的可选开关。移动端与桌面端统一生效。

参考图关键特征：每门课一个鲜亮的纯色（轻微纵向渐变）圆角卡片，课名白色加粗，`@教室` 与教师为半透明白；未排进当前周的课程以灰色淡化卡片显示并带「非本周」标记。

## Requirements

### R1 课程格子新视觉（默认生效，无开关）

- 调色板从浅色（`bg-*-100/70 + text-slate-800`）换成鲜亮实色（参考图色系：青绿 / 蓝 / 品红 / 橙 / 紫 / 金黄等），白色文字；课名加粗，教室带 `@` 前缀，教师/备注为半透明白。
- 圆角卡片：格子有圆角和小间隙，卡片带轻微纵向渐变与细描边，视觉上浮在网格之上。
- 配色仍按课程 ID 稳定哈希（同一门课颜色不变），颜色数量与现有 8 色一致。
- 出勤状态不再用「红/绿描边 + 左侧色条」表达（与新底色冲突），改为 R2 的图标+淡化。
- **信息完整性（用户硬性要求）**：任何尺寸、任何缩放档位下，课名与 `@教室` 必须完整可见——不截断（去掉桌面端 `md:line-clamp-2`）、不被卡片高度裁剪。

### R2 出勤状态表达（默认开，可关）

- 已上：卡片保持鲜亮，右下角白色 ✓ 小图标。
- 未上：卡片整体淡化（降不透明度/去饱和），右下角白色 ! 小图标。
- 个人中心新增开关「在课表上显示出勤状态」：关闭后格子不显示出勤图标、不做淡化，纯参考图样式。默认开启（保持现有语义可见）。

### R3 非本周课程灰色显示（默认关，可开）

- 个人中心新增开关「淡化显示非本周课程」：开启后，本周不上的课程（单/双周、区间周之外）以灰色淡化卡片渲染在对应格子里，课名前带「非本周」标记（沿用现有单双周标签的位置/层级）。
- 默认关闭：保持现有「只显示本周课」的行为，老用户无感知。
- 冲突规则：同一格子里本周课优先；多个非本周课时间重叠时只显示第一门（稳定顺序），其余不渲染（已知限制，写进文档）。
- 非本周课程格子可点击，点开现有课程详情对话框（只读信息不变）。


### R5 教师/备注的空间自适应（放得下就显示，放不下隐藏）

- **实测降级，不用高度阈值**：格子渲染后实测一次内容高度，按「单双周/「非本周」标签 → 教师 → 备注」从低到高整行丢弃，直到放得下。理由：Tailwind v4 不生成高度条件容器查询的 CSS（实测 `@container` 命中数为 0，教师/备注会永不显示）；且同一高度下 20 字课名占 7 行、3 字课名占 1 行，阈值本身区分不出。
- 兜底：整行都丢完仍放不下（例如只有一节的矮格遇上超长课名）时，按需收小课名与 `@教室` 的字号与行高（最多两档），保证这两行完整。
- 硬要求：课名与 `@教室` **永不丢弃**；只有教师/备注/单双周标签参与降级。
- 行高一并**适度加长**：节次行高下限 `2.75rem → 4rem`，让常见的二连节格子（412×915 下 126px）放得下课名 + 教室 + 教师；代价是整周需要竖向滚动（可接受）。
- 本条覆盖 `.trellis/spec/frontend/mobile-schedule-layout.md` 里「教室仅 ≥1.5x、教师仅 2x、桌面端不显示教师」的旧分级，收尾时已同步更新该 spec。
### R4 设置入口

- 个人中心新增「课表显示」设置卡片（跟在现有设置卡片的模式之后），包含 R2、R3 两个 Switch，说明文案清楚。
- 设置持久化（localStorage），刷新/重启后保留。

## Constraints

- 必须遵守 `.trellis/spec/frontend/mobile-schedule-layout.md` 契约：不改移动端网格最小宽度与列宽行为；手机端课名不加 line-clamp；断点统一 `md:`；节次时间只出现在最左列；缩放只改列宽不改字号。
- 保留全部 `data-course-cell` / `data-course-name` / `data-course-parity` / `data-schedule-*` 测试挂钩（可新增，不可移除/改名）。
- 深色模式下新配色对比度可读（白字实底天然兼容，需验证未上淡化态）。
- 不影响桌面小组件、课表导出等其他功能；颜色仅改课表页格子。

## Acceptance Criteria

- [ ] AC1 课表页课程格子为彩色实底（同课程 ID 颜色稳定）、白字、圆角卡片样式，移动端与桌面端一致；教室显示为 `@xxx`；课名与 `@教室` 在手机 1x/1.5x/2x、窄屏（360px）、桌面宽屏下均完整可见，无截断无半截。
- [ ] AC2 默认状态下：已上课的格子鲜亮且带 ✓，未上课的格子整体淡化且带 !；旧的红/绿描边与左侧色条已移除。
- [ ] AC3 个人中心可关闭出勤状态显示，关闭后格子无图标无淡化；设置刷新后保留。
- [ ] AC4 个人中心开启「淡化显示非本周课程」后，非本周课程以灰色淡化卡片 + 「非本周」标记出现；本周课与其重叠时本周课优先；关闭后恢复只显示本周课。
- [ ] AC5 移动端 1x/1.5x/2x 缩放与列宽行为不变（1x 无横向滚动）；课名与 `@教室` 在所有档位/尺寸完整可见，教师/备注按实测空间整行显现或整行隐藏（无半截）；`data-schedule-*` / `data-course-*` 挂钩全部仍在。
- [ ] AC6 `pnpm lint`、`pnpm typecheck`、`pnpm test` 通过；新增纯逻辑（可见课程计算）有单测覆盖。
- [ ] AC7 深色模式下格子与文字可读。
