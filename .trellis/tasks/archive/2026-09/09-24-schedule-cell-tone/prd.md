# 课表配色柔化 + 网格线统一

## Goal

真机验收反馈：① 格子配色过饱和；② 网格线断断续续（有课程的格子没贴线）；③ 第一版柔和色仍然饱和、白字小行糊、相邻色相分不清；④ 教室的 `@` 前缀多余（字号差异已足够区分课名与教室）；⑤ 文字阴影丑。最终方向：web 设计惯例的「pastel 浅底 + 深色字」，网格线全量连续，去掉 `@` 与阴影。

## Requirements

### R1 配色重设计：pastel 浅底 + 深色字（文字优先，颜色不喧宾夺主）

- 底色：8 组 pastel 浅色渐变（各色相 `200→100` 档），低饱和高亮度，颜色退为背景。
- 课名：同色相 700 档文字色（`courseTitleColors`，与 `courseColors` 同哈希档位），保住色相身份与对比度。
- 教室/教师/备注：slate 中性灰（600/500），靠字号与字重分层。
- 8 个色相均匀散布（rose/orange/amber/lime/emerald/sky/indigo/fuchsia，间隔 ≥35°），杜绝「深绿浅绿分不清」。
- 非本周：`slate-200→100` 浅灰卡 + slate 文字 + `opacity-75`。
- 不加任何文字阴影。

### R2 网格线统一

- 所有行/列显示连续细线：有课程的格子同样贴 `border-r`/`border-b`，课程卡内缩 1px 落在线格上；空格线不变；节次列与表头分隔线不变。

### R3 去掉教室的 `@` 前缀

- 课表格子里教室直接显示文本（如 `28-A203`），课名与教室靠字号/字重/颜色分层区分。

## Constraints

- 不动空间自适应降级、出勤痕迹、非本周逻辑、缩放与手势；保留全部 `data-*` 测试挂钩。
- `courseColors` 仍是 8 组、仍由课程 ID 稳定哈希；断点统一 `md:`。

## Acceptance Criteria

- [x] AC1 平色 + 纯白字、无阴影无渐变；实测 sat 0.34–0.56、lum 0.60–0.69、色相最小间隔 29°、课名白字对比 ≥2.07
- [x] AC2 网格线全量连续：18 个课程格容器全部贴 border-r/border-b（周日列按设计无右边线），与空格同规则
- [x] AC3 教室无 `@` 前缀（DOM 断言 @ 残留=0）；课名纯白加粗、教室小一号白色 85%，层级由排版区分
- [x] AC4 空间降级/出勤/非本周/缩放逻辑未动；1x 复验 clipped=0、教师行照常
- [x] AC5 lint/typecheck/test 全绿（261 测试/34 文件）；移动 1x 与桌面截图复验通过
