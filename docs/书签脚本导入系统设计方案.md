# 书签脚本导入系统设计方案

## 背景

ClassTrack 当前已有“学校选择 + 课程表 JSON 解析器 + 本地课程写入”的导入基础。真实教务系统导入的核心问题不是解析课程模型，而是让用户在已登录教务系统的上下文中拿到课程接口响应 JSON。

普通 Web 应用无法直接读取另一个域名下的教务系统页面、Cookie 或接口响应，因此本方案采用书签脚本：脚本由 ClassTrack 生成，但在用户登录后的教务系统页面执行，浏览器会自动携带该页面的登录态请求课程接口，并下载响应 JSON。

## 目标

- 用户选择学校和“通过课程表 JSON 导入”后，进入分步引导弹窗。
- 第一步引导用户安装学校专属书签脚本。
- 第二步打开该学校开发者定义好的课程表页面完整链接。
- 第三步让用户回到 ClassTrack 上传书签脚本导出的 JSON 文件。
- 书签脚本和课程解析器一样可扩展，方便开源贡献者为新学校开发适配。
- ClassTrack 不接触用户教务系统账号密码，不保存教务系统 Cookie。

## 用户流程

1. 用户在“选择学校与导入方式”弹窗中选择学校。
2. 用户选择“从课程表解析”。
3. 用户点击“下一步”，进入“通过课程表 JSON 导入”弹窗。
4. 弹窗第 1 步展示学校专属书签脚本，用户拖到书签栏或复制后手动新建书签。
5. 用户点击“下一步”，查看操作说明。
6. 用户点击“打开课程表页面”，ClassTrack 在新标签页打开学校教务系统课程表地址。
7. 用户在教务系统中登录并进入课程表页面。
8. 用户点击浏览器书签栏里的 ClassTrack 书签脚本。
9. 书签脚本请求课程接口，自动下载课程响应 JSON。
10. 用户回到 ClassTrack，上传 JSON 文件并选择解析器导入。

## 架构设计

### 1. 课程解析器

课程解析器继续负责把原始 JSON 转换为 ClassTrack 的 `Class[]`。

位置：

- `app/lib/parsers/index.ts`
- `app/lib/parsers/*.ts`

解析器接口：

```ts
export interface ClassParser {
  id: string
  name: string
  description: string
  parse: (data: any) => Class[]
}
```

### 2. 书签脚本适配器

新增书签脚本适配器，专门负责“如何从某个学校的教务系统导出原始 JSON”。

位置：

- `app/lib/bookmarklets/index.ts`：统一注册所有书签脚本器。
- `app/lib/bookmarklets/<school-id>/`：单个学校的书签脚本器目录，目录内包含该脚本器的所有必要文件。

推荐目录结构：

```text
app/lib/bookmarklets/
├── index.ts
└── example-university/
    ├── index.ts
    └── script.ts
```

类型定义：

```ts
export interface BookmarkletAdapter {
  id: string
  schoolId: string
  name: string
  description: string
  educationalSystemUrl: string
  defaultTerm: string
  createScript: (params: { term: string }) => string
}
```

字段说明：

- `id`：书签脚本适配器唯一 ID。
- `schoolId`：绑定学校 ID，需要和 `schools` 中的学校 ID 一致。
- `name`：展示给用户的脚本名称。
- `description`：说明该脚本适用的系统、页面和注意事项。
- `educationalSystemUrl`：课程表页面完整链接，由贡献者开发适配时定义。
- `defaultTerm`：默认学年学期参数。
- `createScript`：根据参数生成要在教务系统页面执行的脚本内容。

### 3. 导入弹窗

导入弹窗由单步 JSON 上传改为三步流程。

位置：

- `app/components/dialog/ImportDialog.tsx`

职责：

- 根据当前学校查找 `BookmarkletAdapter`。
- 生成可拖拽到书签栏的脚本链接。
- 引导用户打开学校课程表页面。
- 接收书签脚本导出的 JSON 文件。
- 调用已有课程解析器完成导入。

## 贡献者适配新学校步骤

### 第一步：注册学校

在 `app/lib/parsers/index.ts` 的 `schools` 中增加学校：

```ts
{
  id: 'example-university',
  name: '示例大学',
}
```

### 第二步：新增课程解析器

在 `app/lib/parsers/example-university.ts` 中实现解析器：

```ts
export const exampleUniversityParser: ClassParser = {
  id: 'example-university',
  name: '示例大学',
  description: '适用于示例大学教务系统导出的 JSON 课程表',
  parse: (data: any): Class[] => {
    // 将原始响应转换成 Class[]
    return []
  },
}
```

然后在 `app/lib/parsers/index.ts` 注册。

### 第三步：新增书签脚本适配器

每个书签脚本器必须放在独立目录中，例如 `app/lib/bookmarklets/example-university/`。

`script.ts` 负责生成脚本内容：

```ts
export function createScript({ term }: { term: string }) {
  return `(async()=>{/* 请求课程接口并下载 JSON */})()`
}
```

`index.ts` 负责导出适配器元信息：

```ts
import type { BookmarkletAdapter } from '../../types'
import { createScript } from './script'

export const exampleUniversityBookmarklet: BookmarkletAdapter = {
  id: 'example-university-bookmarklet',
  schoolId: 'example-university',
  name: '示例大学教务课表导出',
  description: '登录示例大学教务系统后，在课表页面执行书签脚本导出 JSON。',
  educationalSystemUrl: 'https://jw.example.edu.cn/path/to/schedule',
  defaultTerm: '2025-2026-2',
  createScript,
}
```

最后在 `app/lib/bookmarklets/index.ts` 统一注册：

```ts
import { exampleUniversityBookmarklet } from './example-university'

export const bookmarkletAdapters = [exampleUniversityBookmarklet]
```

## 书签脚本开发规范

书签脚本必须满足：

- `createScript` 只返回要执行的脚本内容，不需要包含 `javascript:` 前缀。
- 在教务系统页面上下文中执行。
- 请求接口时使用 `credentials: 'include'`。
- 不要求用户输入账号密码。
- 自动下载原始响应 JSON。
- 在控制台打印关键日志，便于调试。
- 失败时给出明确提示。

推荐下载逻辑：

```js
const blob = new Blob([JSON.stringify(data, null, 2)], {
  type: 'application/json;charset=utf-8',
})
const url = URL.createObjectURL(blob)
const link = document.createElement('a')
link.href = url
link.download = 'classtrack-course.json'
document.body.appendChild(link)
link.click()
link.remove()
setTimeout(() => URL.revokeObjectURL(url), 1000)
```

## 安全边界

- ClassTrack 不收集用户教务系统账号密码。
- ClassTrack 不读取教务系统 Cookie。
- 请求发生在用户浏览器的教务系统页面内。
- 导出的 JSON 文件由用户手动上传到 ClassTrack。
- 贡献者提交适配器时，应避免把任何个人 Cookie、Token、学号等敏感信息写入代码。

## 后续演进

- 将 `term` 参数扩展为学校自定义参数表单。
- 增加导入预览页，展示课程数量、教师、教室、周次和节次。
- 将书签脚本适配器拆分为独立文件，便于按学校维护。
- 支持书签脚本导出标准包装格式，例如 `{ source, capturedAt, data }`。
- 后续可基于同一适配器模型开发浏览器插件，实现更接近一键导入的体验。
