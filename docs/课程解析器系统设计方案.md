# 课程解析器系统设计方案

## 背景

课程解析器系统负责将各高校教务系统导出的原始 JSON 数据解析为 ClassTrack 统一的 `Class[]` 格式。每个学校的教务系统接口返回的数据结构不同，因此需要为每个学校编写独立的解析器。

## 文件架构

采用与标签脚本系统（bookmarklets）一致的**文件夹式架构**，每个学校独立一个目录：

```
app/lib/parsers/
├── index.ts                                    # 中央注册和导出
├── tianjin-university-of-technology/           # 天津理工大学
│   ├── index.ts                                # 解析器元数据定义
│   └── parser.ts                               # 解析逻辑实现
└── tianjin-polytechnic-university/             # 天津工业大学
    ├── index.ts                                # 解析器元数据定义
    └── parser.ts                               # 解析逻辑实现
```

### 架构对比

| 模块 | 标签脚本系统 | 课程解析器系统 |
|------|------------|--------------|
| 根目录 | `bookmarklets/` | `parsers/` |
| 学校目录 | `<school>/` | `<school>/` |
| 入口文件 | `index.ts`（元数据） | `index.ts`（元数据） |
| 逻辑文件 | `script.ts`（脚本生成） | `parser.ts`（解析逻辑） |
| 注册方式 | `bookmarklets/index.ts` 集中导入 | `parsers/index.ts` 集中导入 |

## 类型定义

类型定义位于 `app/lib/types.ts`：

```typescript
// 解析后的课程数据类型
export interface Class {
  id: string           // 唯一标识符
  name: string         // 课程名称
  teacher: string      // 教师
  classroom: string    // 教室
  startTime: string    // 开始时间
  endTime: string      // 结束时间
  dayOfWeek: number    // 星期几 (1-7)
  startSection: number // 开始节次
  endSection: number   // 结束节次
  weeks: number[]      // 周次数组
  semester: string     // 学年学期
  courseId: string      // 课程号
  classId: string      // 教学班ID
  courseType: string    // 课程性质
  courseCategory: string // 课程类别
}

// 解析器类型
export interface ClassParser {
  id: string
  name: string
  description: string
  parse: (data: any) => Class[]
}
```

## 完整实现

### 1. 中央注册文件 `parsers/index.ts`

```typescript
import type { ClassParser, School } from '../types'

// 导入所有解析器
// 新增解析器：在 parsers/ 目录下创建新的学校文件夹，然后在此处导入
import { tianjinUniversityOfTechnologyParser } from './tianjin-university-of-technology'
import { tianjinPolytechnicUniversityParser } from './tianjin-polytechnic-university'

// 解析器注册表
export const parsers: ClassParser[] = [tianjinUniversityOfTechnologyParser, tianjinPolytechnicUniversityParser]

// 学校列表（学校与解析器不绑定，选择学校后仍可自由选择任意解析器）
export const schools: School[] = [
  {
    id: 'tianjin-university-of-technology',
    name: '天津理工大学',
  },
  {
    id: 'tianjin-polytechnic-university',
    name: '天津工业大学',
  },
]

// 根据ID获取解析器
export function getParserById(id: string): ClassParser | undefined {
  return parsers.find((p) => p.id === id)
}
```

#### `tianjin-university-of-technology/parser.ts`

```typescript
import type { Class } from '../../types'

export function parseWeeks(skzc: string): number[] {
  const weeks: number[] = []
  for (let i = 0; i < skzc.length; i++) {
    if (skzc[i] === '1') {
      weeks.push(i + 1)
    }
  }
  return weeks
}

export function generateClassId(rawClass: any): string {
  return `${rawClass.JXBID}-${rawClass.SKXQ}-${rawClass.KSJC}`
}

export function parse(data: any): Class[] {
  const rawClasses = data?.datas?.cxxszhxqkb?.rows

  if (!Array.isArray(rawClasses) || rawClasses.length === 0) {
    throw new Error('未解析到课程数据')
  }

  return rawClasses.map((rawClass) => ({
    id: generateClassId(rawClass),
    name: rawClass.KCM,
    teacher: rawClass.SKJS,
    classroom: rawClass.JASMC,
    startTime: rawClass.KSSJ,
    endTime: rawClass.JSSJ,
    dayOfWeek: rawClass.SKXQ,
    startSection: rawClass.KSJC,
    endSection: rawClass.JSJC,
    weeks: parseWeeks(rawClass.SKZC),
    semester: rawClass.XNXQDM,
    courseId: rawClass.KCH,
    classId: rawClass.JXBID,
    courseType: rawClass.KCXZDM_DISPLAY,
    courseCategory: rawClass.KCLBDM_DISPLAY,
  }))
}
```

## 贡献新解析器

适配新学校只需三步：

### 步骤 1：创建学校目录

在 `app/lib/parsers/` 下创建以学校英文名（kebab-case）命名的目录：

```
app/lib/parsers/your-university/
├── index.ts
└── parser.ts
```

### 步骤 2：实现解析器

**`your-university/parser.ts`**：

```typescript
import type { Class } from '../../types'

export function parse(data: any): Class[] {
  // TODO: 根据学校教务系统返回的 JSON 结构实现解析
  // 必须返回符合 Class 接口的数组
  return []
}
```

**`your-university/index.ts`**：

```typescript
import type { ClassParser } from '../../types'
import { parse } from './parser'

export const yourUniversityParser: ClassParser = {
  id: 'your-university',
  name: '你的学校名称',
  description: '适用于XXX教务系统导出的JSON课程表',
  parse,
}
```

### 步骤 3：注册解析器

在 `parsers/index.ts` 中导入并添加到注册表：

```typescript
import { yourUniversityParser } from './your-university'

export const parsers: ClassParser[] = [
  // ...已有解析器
  yourUniversityParser,
]
```

## 设计原则

1. **模块隔离**：每个学校的解析逻辑完全独立，互不影响
2. **职责分离**：`index.ts` 负责元数据定义，`parser.ts` 负责解析逻辑
3. **统一接口**：所有解析器实现相同的 `ClassParser` 接口
4. **中央注册**：通过 `parsers/index.ts` 统一管理所有解析器的导入和导出
5. **与标签脚本系统对齐**：采用一致的文件夹式架构，降低贡献者的学习成本
